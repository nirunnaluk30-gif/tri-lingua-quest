# TRI-LINGUA Quest — เวอร์ชันเว็บไซต์ของโรงเรียน (GitHub Pages + Firebase)

เกมฝึก 3 ภาษา ไทย · English · 中文 ที่ทุกคนเข้าเล่นได้ด้วย **ID + รหัสผ่าน** ไม่ต้องมีอีเมล ไม่ต้องมีบัญชี Claude

- หน้าเว็บอยู่บน **GitHub Pages** (ฟรี)
- ข้อมูลผู้เล่น คำศัพท์ และการตั้งค่าทั้งหมดอยู่บน **Firebase** ของโรงเรียน (แผนฟรี Spark)
- ไฟล์ทั้งหมดในโฟลเดอร์นี้อัปโหลดขึ้น GitHub ได้ทันที

ใช้เวลาตั้งค่าครั้งแรกประมาณ 20–30 นาที ทำตามข้อ 1–7 ตามลำดับ

---

## 1. สร้างโปรเจกต์ Firebase

1. เข้า <https://console.firebase.google.com> ด้วยบัญชี Google ของโรงเรียน
2. กด **Create a project / เพิ่มโปรเจกต์** → ตั้งชื่อ เช่น `tri-lingua-quest`
3. ปิด Google Analytics ได้ (ไม่จำเป็น) → **Create project**

## 2. เอาค่าการเชื่อมต่อมาใส่ใน `config.js`

1. ในหน้าโปรเจกต์ กดไอคอน **`</>` (Web)** เพื่อเพิ่มเว็บแอป → ตั้งชื่อ → **Register app**
   (ไม่ต้องติ๊ก Firebase Hosting)
2. จะเห็นโค้ด `const firebaseConfig = { apiKey: "...", ... }`
3. คัดลอกค่าในวงเล็บ `{ ... }` ไปแทนที่ค่าในไฟล์ **`config.js`** ให้ครบทุกบรรทัด

> ค่าชุดนี้เป็นเพียง "ที่อยู่" ของฐานข้อมูลสำหรับหน้าเว็บ เปิดเผยได้ตามปกติ
> ความปลอดภัยของข้อมูลมาจาก **กฎในข้อ 4** — ห้ามข้ามข้อ 4

## 3. เปิดระบบเข้าสู่ระบบด้วย ID/รหัสผ่าน

1. เมนูซ้าย **Build → Authentication → Get started**
2. แท็บ **Sign-in method** → เลือก **Email/Password** → เปิด **Enable** (อันแรก) → **Save**
   (ระบบใช้ช่องนี้เก็บ ID ของนักเรียน ไม่มีการส่งอีเมลใด ๆ)
3. แท็บ **Settings → Authorized domains** → **Add domain** → ใส่ `ชื่อผู้ใช้GitHub.github.io`

## 4. สร้างฐานข้อมูล และใส่กฎความปลอดภัย ⚠️ สำคัญมาก

1. เมนูซ้าย **Build → Firestore Database → Create database**
2. เลือกตำแหน่ง **asia-southeast1 (Singapore)** → เลือก **Production mode** → **Create**
3. ไปที่แท็บ **Rules** → ลบข้อความเดิมทั้งหมด → คัดลอกเนื้อหาไฟล์ **`firestore.rules`** ไปวาง → **Publish**

กฎนี้ทำให้ นักเรียนเห็น/แก้ได้เฉพาะข้อมูลของตัวเอง, ข้อมูลส่วนตัวและคำขอเติมเพชรเห็นได้เฉพาะครู, และแก้เนื้อหาเกมได้เฉพาะผู้ดูแล

## 5. อัปโหลดขึ้น GitHub Pages

1. เข้า <https://github.com> → **New repository** → ตั้งชื่อ เช่น `tri-lingua-quest` → เลือก **Public** → **Create**
2. ในหน้า repo กด **Add file → Upload files** → ลาก**ไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้**
   (`index.html`, `config.js`, `backend-firebase.js`, โฟลเดอร์ `assets`, ฯลฯ) → **Commit changes**
3. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → **Save**
4. รอ 1–2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/tri-lingua-quest/` — นี่คือลิงก์สำหรับทำ QR โค้ด

> แก้ `config.js` ทีหลังได้บนเว็บ GitHub: เปิดไฟล์ → ไอคอนดินสอ ✏️ → วางค่า → **Commit changes**

## 6. สมัคร ID ของครู แล้วตั้งตัวเองเป็นผู้ดูแล

1. เปิดลิงก์เกม → แท็บ **สมัครสมาชิก** → ตั้ง ID เช่น `teacher01` + รหัสผ่าน → กรอกชื่อ เลือกระดับชั้น "ครู/บุคลากร" → สมัคร
2. กลับไปที่ Firebase → **Firestore Database → Data → + Start collection**
   - Collection ID: `admins`
   - Document ID: **`id_teacher01`** (คำว่า `id_` ตามด้วย ID ที่สมัคร ตัวพิมพ์เล็ก)
   - เพิ่ม field: `at` ชนิด number ค่า `1` → **Save**
3. กลับไปที่เกม กดรีเฟรช → จะเห็นปุ่ม **⚙️ ผู้ดูแลระบบ** บนหน้าแรก

ครูคนอื่นเพิ่มเป็นผู้ดูแลได้จากในเกม: หน้าแอดมิน → **ห้องเรียนและการสมัคร** → ส่วน **ผู้ดูแลระบบ**

## 7. ใส่เนื้อหาเกมครั้งแรก

1. เข้าหน้าแอดมิน → ภาพรวม → กด **ใส่ข้อมูลเริ่มต้นทั้งหมด** (คำศัพท์ 230 คำ ด่าน ไอเทม สัตว์เลี้ยง ฯลฯ)
2. ตั้งค่า **ห้องเรียนและการสมัคร** (รายชื่อห้อง, บังคับกรอกข้อมูล)
3. ปรับ **ตกแต่งเว็บ** ตามต้องการ แล้วแจกลิงก์/QR ให้นักเรียนได้เลย 🎉

## การดูแลประจำ

| เรื่อง | วิธีทำ |
|---|---|
| **นักเรียนลืมรหัสผ่าน** | Firebase → Authentication → Users → ค้นหา `id_<ID>@id.trilingua.local` → ⋮ → **Delete account** → ให้นักเรียนสมัครใหม่ด้วย **ID เดิม** ความคืบหน้ายังอยู่ครบ |
| เปลี่ยนรหัสผ่านเอง | นักเรียนเข้าหน้า **ฉัน → เปลี่ยนรหัสผ่าน** |
| สำรองข้อมูล | หน้าแอดมิน → **สำรอง/กู้คืน** → ดาวน์โหลดไฟล์ JSON เก็บไว้เป็นระยะ |
| อัปเดตเกมเวอร์ชันใหม่ | อัปโหลด `index.html` ใหม่ทับใน GitHub (ไม่ต้องแตะ `config.js`) |
| ปิดรับสมัครชั่วคราว | หน้าแอดมิน → ห้องเรียนและการสมัคร → ปิด "เปิดรับสมัครสมาชิกใหม่" |

## โควตาฟรี (Firebase Spark)

- อ่านข้อมูล 50,000 ครั้ง/วัน, เขียน 20,000 ครั้ง/วัน, พื้นที่ 1 GB
- เกมนี้รวมเนื้อหาไว้เป็นก้อน นักเรียน 1 คนเข้าเล่น 1 รอบใช้ประมาณ 20–60 ครั้งอ่าน
  → รองรับการเข้าเล่นประมาณ **800–2,000 รอบต่อวัน** ฟรี
- ถ้าใช้งานเกิน ระบบจะหยุดรับข้อมูลจนถึงวันถัดไป (ไม่มีค่าใช้จ่ายเอง เว้นแต่อัปเกรดเป็นแผน Blaze)
- ดูการใช้งานได้ที่ Firebase → Firestore → **Usage**

## ความเป็นส่วนตัวของนักเรียน (PDPA)

- ระบบเก็บเฉพาะ: ID, ชื่อ-นามสกุล, ระดับชั้น, ห้อง/เลขที่ (ถ้ากรอก) และผลการเล่น
- รหัสผ่านเก็บโดย Firebase แบบเข้ารหัส ครูและผู้พัฒนาไม่เห็นรหัสจริง
- ข้อมูลส่วนตัวเห็นได้เฉพาะผู้ดูแล — เพื่อนในเกมเห็นแค่ชื่อตัวละคร
- แนะนำให้โรงเรียนแจ้งผู้ปกครองว่ามีการเก็บข้อมูลเพื่อการเรียนรู้ และจัดการลบข้อมูลเมื่อมีผู้ขอ

## โครงสร้างไฟล์

```
index.html            ตัวเกมทั้งหมด
config.js             ค่าการเชื่อมต่อ Firebase ของโรงเรียน (แก้ไฟล์นี้)
backend-firebase.js   ตัวเชื่อมเกมกับ Firebase (ไม่ต้องแก้)
firestore.rules       กฎความปลอดภัย (คัดลอกไปวางใน Firebase)
assets/               ภาพและแอนิเมชันหน้าเข้าเกม
```
